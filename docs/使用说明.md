# Arknights Painter 使用说明

Arknights Painter 用于把普通图片转换成 24×24 像素画，并把每个格子的点击操作发送到安卓模拟器或原生电脑版的绘画页面。本文以 Windows 11 和横屏绘画页面为例，介绍从连接设备到完成绘制的完整流程。

> 本工具只负责输入画面，不会自动点击保存、发布或提交。使用前请确认目标软件允许使用自动化输入，并自行备份重要内容。

## 一、准备工作

### 1. 下载程序

从 [GitHub Releases](https://github.com/Dr-hydra/Arknights-Painter/releases/latest) 下载 `ArknightsPainter-v1.1.1-win-x64.zip`，完整解压到普通目录后运行 `ArknightsPainter.App.exe`。不要只把 EXE 单独移出，因为电脑版组件和备用 ADB 位于随包的 `Assets` 目录中。

发布包是 win-x64 .NET 10 自包含版本，并内置 Android Platform Tools ADB 35.0.2 作为降级方案，通常不需要另外安装 .NET 运行时或 ADB。当前版本支持 64 位 Windows 10 19041 及以上系统，推荐使用 Windows 11。

### 2. 准备目标画面

1. 安卓版：启动安卓模拟器，并确认 ADB 调试已开启且已经授权。
2. 电脑版：启动 `Arknights.exe`，进入标题为“明日方舟”的游戏窗口。
3. 进入目标软件的横屏 24×24 绘画页面。
4. 进入绘画页面后即可连接；建议不要在绘制期间切换页面或改变窗口/模拟器分辨率。
5. 电脑版模式支持窗口被其他窗口遮挡或暂时最小化时取图，但游戏自身的权限限制、弹窗和渲染状态仍可能影响识别。

## 二、连接设备

### 安卓模拟器：ADB

1. 启动 `ArknightsPainter.App.exe`。
2. 在右侧选择“模拟器”按钮，然后点击设备列表旁的刷新按钮。
3. 程序会优先检查已填写的路径，也会自动检查 MuMu、雷电、蓝叠、Android SDK 和系统 PATH；均不可用时自动使用软件自带的 ADB。需要指定版本时，可在“ADB 路径”中填写完整路径，例如：

   ```text
   C:\Program Files\Netease\MuMuPlayer-12.0\shell\adb.exe
   ```

4. 如果模拟器使用 TCP 连接，在“TCP 端点”中填写模拟器地址，默认值为 `127.0.0.1:16384`，然后点击“连接”。
5. 在设备列表中选择状态为 `device` 的设备。

只有设备在线时才能进行截图、校准和绘制。常见状态含义如下：

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| `device` | 已在线并可操作 | 可以继续 |
| `offline` | ADB 连接未完成 | 重启 ADB 或重新连接模拟器 |
| `unauthorized` | 未授权当前电脑 | 在模拟器中确认 USB/ADB 授权提示 |
| 未发现设备 | 路径或连接不正确 | 检查 ADB 路径、端点和模拟器设置 |

### 原生电脑版：窗口 PID

1. 在右侧“连接设备”下点击“电脑版”按钮。程序会检查当前权限；不是管理员权限时会弹出 Windows UAC，并以管理员权限重新启动。
2. 在“电脑版进程 PID”中填写游戏进程 PID，例如任务管理器中显示的 `25760`。
3. 点击“绑定”。列表中出现 `win32:25760` 且状态为在线后即可校准。

电脑版后端复用 MaaFramework 的 Win32 控制单元：使用 FramePool/PrintWindow 获取目标窗口客户区，并使用带光标定位的窗口消息发送点击和滑动，不需要 ADB。若取消 UAC，程序会切回模拟器模式。游戏也以管理员权限运行时，两者权限级别必须一致。PID 留空时会按窗口标题“明日方舟”或进程名自动发现；也可以填写任务管理器“详细信息”页中的 PID。重启游戏后 PID 通常会变化，移动或调整窗口大小后建议重新校准。

## 三、导入图片并转换

### 1. 导入和裁切

支持 PNG、JPEG、BMP、WebP 和 SVG。可以点击“打开图片”选择文件，也可以把图片拖入左侧导入区域。导入后，中间会显示 24×24 预览和颜色统计。

SVG 会先按原始比例安全栅格化，最长边限制为 2048 像素，并保留透明通道；之后继续使用与普通图片相同的裁切、构图和色板量化流程。为了避免导入文件访问网络或本地文件，程序会拒绝包含脚本、事件处理器、外部图片或外部样式资源的 SVG。单个 SVG 文件最大为 8 MB。

如果图片主体周围有水印或多余内容，点击图片区域旁的裁切按钮，在裁切窗口中调整范围并保存。裁切窗口显示的是导入图片本身；画面校准窗口显示的则是之后从模拟器获取的实时截图，两者不要混淆。

### 2. 选择构图方式

- **完整适配**：保持原图比例，完整内容缩放到 24×24，空白区域使用背景色填充。适合不希望裁掉主体的图片。
- **居中裁切**：保持比例铺满画布，超出部分从四周裁掉。适合主体位于图片中央的方形构图。
- **直接拉伸**：不保持比例，直接拉伸到 24×24。适合原图比例接近目标画布的情况。

### 3. 选择转换算法

- **拼豆均色**：对每个目标格进行面积采样后量化，照片、插画和渐变图片通常更自然。
- **拼豆主色**：更重视格子内出现频率最高的颜色，适合 Logo、图标和已有像素画，轮廓更明确。
- **感知平滑**：使用感知色差进行平滑映射，适合希望减少突兀色块、保留整体色调的图片。

### 4. 设置背景和抖动

“留白颜色”只影响完整适配时的空白区域，也会纳入 576 个格子的绘制，因此可以覆盖画布上原有内容。

抖动默认关闭。需要表现细微渐变时，可以尝试：

- **Atkinson**：纹理较轻，适合人物和插画。
- **Floyd-Steinberg**：细节和颗粒感更明显，适合照片或复杂渐变。
- **Bayer 4×4**：规律性较强，适合复古像素风格。

每次修改构图、算法、背景或抖动方式后，程序会重新生成预览。开始绘制前请检查主体位置、背景颜色和颜色统计是否符合预期。

## 四、画面校准

### 1. 自动识别

1. 确认目标窗口仍停留在目标绘画页面。
2. 点击右侧“自动识别”。
3. 程序会从当前连接方式获取**实时截图**：安卓使用 ADB，电脑版使用窗口客户区截图。随后利用画板四角定位线、左右中点十字定位点、外框和 24×24 网格识别画布；颜料区域会根据当前页面布局定位。
4. 识别成功后，右侧会显示屏幕分辨率和校准置信度。

首次使用或更换模拟器分辨率时建议重新校准。校准结果按设备序列号和截图分辨率保存到：

```text
%LOCALAPPDATA%\ArknightsPainter\settings.json
```

### 2. 手动调整

自动识别失败时，点击“手动调整”。窗口中的背景图来自当前设备的实时截图，不是导入的图片，也不会受到导入图片水印的影响。

窗口中有两个矩形：

- 蓝色“画布”框：覆盖完整的 24×24 画板区域，包括边界范围。
- 橙色“颜料”框：覆盖颜料面板的可视区域，包含滚动后需要识别的色块。

拖动矩形移动位置，拖动右下角方块调整大小。确认两个区域都完整覆盖后点击“保存校准”。如果只看到截图左半部分，可以先最大化窗口或缩小系统显示缩放，再重新打开手动校准；校准图本身仍是完整设备截图。

## 五、开始绘制

点击“开始绘制”前，程序必须同时满足以下条件：

- 已导入并成功转换图片；
- 已选择状态为 `device` 的在线设备；
- 已存在匹配当前设备序列号和分辨率的校准配置。

开始后程序会先再次截图验证画面结构和内置色板签名。验证通过后按颜料顺序分组绘制，每批最多点击 20 个格子，默认点击间隔约 50 毫秒。每种颜料完成后会截图抽样校验，发现漏画会自动重试一次；仍然失败时会停止绘制并在日志中报告位置。

“绘制安全校验”默认显示“已开启：校验后绘制”。如果目标画面可以正常操作，但视觉校验因缩放、滤镜或版本差异反复误报，可以关闭该开关，界面将明确显示“已关闭：直接绘制”。直接绘制会跳过画布、色板、选色发光和落色结果校验，但仍要求设备在线、完成坐标校准并能定位目标颜料。此选项会记住上次状态，正常情况下建议保持开启。

- **暂停/继续**：暂停在当前批次完成后生效，不会丢失已经完成的格子。
- **F8**：绘制过程中快速切换暂停或继续，行为与界面按钮相同。
- **取消**：立即停止后续操作，不会回滚已经绘制的格子。
- **运行日志**：展开底部“运行日志”查看 ADB、校准、选色和校验信息。

绘制过程中请让模拟器保持前台页面可见，不要手动点击画板或滚动颜料面板。完成后请在目标软件中自行检查结果，并按需要手动保存或发布。

## 六、推荐设置

| 图片类型 | 构图 | 算法 | 抖动 |
| --- | --- | --- | --- |
| 人物照片、风景照片 | 完整适配或居中裁切 | 拼豆均色 | Atkinson 或 Floyd-Steinberg |
| Logo、图标、表情 | 居中裁切 | 拼豆主色 | 无抖动 |
| 原有像素画 | 直接拉伸或完整适配 | 拼豆主色 | 无抖动 |
| 低对比度插画 | 完整适配 | 感知平滑 | Bayer 4×4 或无抖动 |

这些设置只是起点。最终效果取决于原图尺寸、透明区域、主体位置和目标软件当前色板，建议先观察 24×24 预览，再开始绘制。

## 七、常见问题

### 程序无法启动

优先下载 Releases 中的完整 ZIP，解压后保持 `ArknightsPainter.App.exe` 与 `Assets` 目录的相对位置不变，并将程序放在有写入权限的普通目录。首次启动可能需要几秒钟解压 WinUI 原生组件；如果仍然退出，请确认系统为 64 位 Windows 10 19041 或 Windows 11。

### 找不到 ADB 或设备列表为空

确认 ADB 路径指向实际的 `adb.exe`，在 PowerShell 中运行 `adb devices` 检查设备是否出现。若使用 TCP 连接，先点击“连接”再刷新设备；同时连接多个设备时要在列表中明确选择目标设备。

### 电脑版窗口无法绑定或截图为空

确认 PID 对应的进程仍在运行，游戏窗口标题为“明日方舟”，并且发布目录中存在完整的 `Assets\Maa` 运行库目录。电脑版模式的截图和输入由 MaaFramework Win32 控制单元处理，FramePool/PrintWindow 可以在后台窗口或被遮挡时工作；如果游戏使用了不支持后台捕获的渲染路径、弹出权限对话框或窗口已退出，请恢复目标页面后重新点击“绑定”并校准。调整窗口大小或重新启动游戏后，请重新校准。

### 自动识别失败

确认目标软件已经打开横屏绘画页面，并且画板四周的定位点没有被弹窗、通知栏或其他窗口遮挡。关闭遮挡后重新截图识别；仍失败时使用手动调整，并确保画布框和颜料框都完整覆盖目标区域。

### 开始绘制按钮不可用

检查是否已经导入图片、选择在线设备并完成当前分辨率的校准。更换模拟器分辨率、窗口方向或设备序列号后，需要重新校准。

### 绘制中途暂停或报画面不匹配

不要操作模拟器，先查看运行日志。程序检测到画板结构、色板签名或选中色块发光边框不符合预期时会主动停止，这是为了避免盲目点击。恢复正确页面后重新校准，再点击“开始绘制”。当前版本会重新绘制全部 576 格，以覆盖画板上的现有内容。

## 八、数据和隐私

程序只在本机保存 ADB 路径、TCP 端点和校准矩形，文件位置为 `%LOCALAPPDATA%\ArknightsPainter\settings.json`。导入图片不会上传到网络，ADB 命令只发送到你选择的本地模拟器设备。

项目源码和问题反馈请访问 [GitHub 仓库](https://github.com/Dr-hydra/Arknights-Painter)。
